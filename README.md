# BRONO TRAVAUX

Site vitrine premium de BRONO TRAVAUX, construit avec Next.js et GSAP.

## Démarrage

```bash
npm install
npm run dev
```

Puis ouvrir `http://localhost:3000`.

## Production

```bash
npm run build
npm start
```

## Contenu à valider avant mise en ligne

- Remplacer les trois visualisations d'ambiance par des photographies de réalisations réelles.
- Confirmer le domaine final et le remplacer dans `app/layout.jsx`, `app/sitemap.js` et `app/robots.js`.
- Ajouter l'adresse postale complète, les horaires et les liens sociaux.
- Faire valider les normes, garanties, marques partenaires et délais affichés.
- Connecter un fournisseur d'e-mail si les demandes doivent aussi être stockées ou envoyées par courriel.
